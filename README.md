# 🏥 Smart Web-Based Hospital Management System

A **Smart Web-Based Hospital Management System** is designed to make hospital operations easier, faster, and more organized through a centralized web application. The system allows hospital staff to manage patient information, doctors, appointments, bed availability, and emergency-related services from a single platform.

Instead of handling hospital information manually, the system stores important records in a structured database and provides authorized users with quick access to the required information.

## 🚀 Key Features

* 🔐 **User & Admin Login** – Provides secure access based on the user's role.
* 👤 **Patient Management** – Allows staff to register patients and maintain their hospital records.
* 📅 **Appointment Management** – Enables appointment booking and helps manage scheduled consultations.
* 👨‍⚕️ **Doctor Management** – Maintains doctor information and availability.
* 🛏️ **Bed Availability** – Tracks available and occupied hospital beds.
* 🚨 **Emergency Support** – Provides quick access to emergency-related hospital services.
* 📊 **Hospital Dashboard** – Displays important hospital activities and records in an organized view.

## 🔄 How the System Works

The application follows a simple flow:

**👤 User → 🌐 Web Application → ⚙️ Spring Boot → 🗄️ MySQL Database**

1. 🔐 The user logs into the system through the web interface.
2. 👥 The system provides features according to the user's role.
3. 📝 Patient, doctor, appointment, and bed information can be added, viewed, updated, or deleted.
4. ⚙️ Spring Boot processes the user's request.
5. 🔗 Spring Data JPA communicates with the MySQL database.
6. 📋 The requested or updated information is displayed back on the web application.

## 🗃️ Database Operations

MySQL is used to store and manage important hospital information, including:

* 👤 Patient details
* 👨‍⚕️ Doctor details
* 📅 Appointment records
* 🛏️ Bed availability status
* 👥 User and administrative information

The application performs **CRUD operations — Create, Read, Update, and Delete —** using **Spring Data JPA** to manage database records efficiently.

## 🎯 Project Objective

The main objective of this project is to develop a centralized hospital management platform that reduces manual work and makes hospital information easier to manage. By connecting patient, doctor, appointment, and bed-related information in one system, hospital staff can access and manage important records more efficiently.

## ✅ Project Outcome

The system provides a structured and user-friendly platform for handling essential hospital activities. It demonstrates the integration of **Java, Spring Boot, JSP, Spring Data JPA, and MySQL** to build a practical web-based hospital management application.
